# OmniView 1.12.0

- View PPTX slide text, tables, pictures and speaker notes. Layout, animations and themes are not reproduced; legacy PPT files require conversion.
- Recover unsaved text edits after an unexpected exit, with options to restore or discard drafts.
- Open large code files with bounded initial rendering, whole-file search and improved multiline highlighting.
- Improve PDF page tracking and add installer verification to the Windows release checks.

Windows downloads are unsigned. macOS builds use ad-hoc signing and are not notarized. Check the supplied checksums and build provenance when downloading.
