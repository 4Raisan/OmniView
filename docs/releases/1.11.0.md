# OmniView 1.11.0

- Select, copy and search PDF text; open password-protected PDFs.
- Read spreadsheet dates and number formats as displayed in the workbook.
- Navigate tabs with the keyboard and hear tab state with a screen reader.
- Recognize more file types, display UTF-16 text, and report unsupported formats and media errors clearly.
- Improve document sanitization, archive limits, safe saves and desktop IPC checks.
- Reduce unnecessary file copies and bound PDF printing memory.

Windows downloads are unsigned. macOS builds use ad-hoc signing and are not notarized. Verify download checksums and build provenance before use.
