Legacy Word `.doc` files now open offline in a read-only text view on Windows, Linux and macOS.

- View document text, Unicode, headers, footers, footnotes, endnotes, text boxes and comments when present.
- Open DOC from disk, recent files or inside ZIP archives; zoom, select/copy text and print the text view.
- No Microsoft Word, LibreOffice or online conversion service is required.
- Original page layout, images, table structure and formatting are not reproduced. DOCX retains its formatted view.
- DOC input is limited to 32 MB. Password-protected files, RTF/HTML disguised as DOC and unsupported older formats show an explanatory error.

The reader runs in a separate bounded worker. Checks cover genuine Word 97 files, Unicode, headers/footers, notes, invalid and encrypted inputs, ZIP nesting, tab switching and packaged worker loading.

Downloads include Windows installer/portable, Linux AppImage/DEB, Apple Silicon/Intel macOS DMGs, the complete buildable source ZIP and SHA256SUMS.txt. The extracted source ZIP is built again before upload.

Windows builds are unsigned. Mac builds use ad-hoc signatures and are not notarized. Existing 1.9.0 users see the update notice on their next startup or through Help → Check for updates after this release is published.
